Hi Bryan,

Thanks for the extra detail.

The relay scoring correction is now done: relay/team events score 5 points for 1st, 4 for 2nd and 3 for 3rd.

Completed event results are saved in the app database after an event is finalized. We have also added a completed-category report so the app can show completed results across the event/stroke categories you listed: 25m, 50m, relay, medley relay, 75m, 25m brace, 50m brace, breaststroke, backstroke and butterfly. You listed 75m twice, so we cover the supported 75m category once rather than creating a duplicate category.

The DB can now be exported from the Reports / Pointscore area using the DB & Graphs tab. The button downloads a raw SQLite database snapshot file. Existing CSV exports are still available as well.

The graphs are produced from saved time history rows. When an event is finalized, the app saves swimmer, event date, stroke, current time, previous best and break status into time_history. The individual graph screen reads those rows and plots them for the selected swimmer.

We have also added the two summary reports you asked for: number of breaks per person overall and by event, and total time improvement per person overall and by event. The break report uses time_history.is_break. The improvement report uses the saved current time and previous best and only counts rows where the current time is faster than the previous best.

We have tested this with a completed local retest dataset covering the requested event/stroke categories and verified the reports, CSV exports, DB download and graph source data.
