### Environment note (why this took two passes locally)

The Dropbox-synced `node_modules/better-sqlite3` is a native binary. Balerion's **arm64** QA rebuild on the Mac Mini synced onto this **Intel x86_64** machine mid-session and clobbered the local build, so the server crashed with `ERR_DLOPEN_FAILED (have 'arm64', need 'x86_64')` on the suites' server-restart cases. Fix = `npm rebuild better-sqlite3` immediately before each run (gitignored; commits/evidence unaffected). Balerion independently hit the mirror image and resolved it with a temp copy outside Dropbox. **This is an environment artifact, not a product defect.** Recommend excluding `node_modules` from Dropbox sync to end the ping-pong.
